1. EXECUTIVE SUMMARY

This document defines product requirements for the "Column Addition and Subtraction
within 1000" interactive lesson module, delivered as a standalone lesson within
Intellia SG's Grade 2 Math program. The module targets Singapore Primary 2
students aged 7–8 and teaches column addition and subtraction algorithms with and
without regrouping, using 3-digit numbers up to 1000, fully aligned with the
Singapore MOE Mathematics Framework and the Primary 2 Targeting Mathematics
syllabus.

The product is a standalone web page hosted at:

https://intelliasg.com/courses/grade-1-math/lessons/column-addition-subtraction-within-1000/

It is built using React (Vite + JSX, JavaScript/CSS) and designed to strictly
mirror the visual and UX structure established at https://numberbound.vercel.app/
and the repository https://github.com/dsamyak/numberbound.

Audio narration is delivered via ElevenLabs (Voice: Alice, eleven_multilingual_v2)
using a hybrid pre-generation + dynamic fallback pipeline (see Section 11).

The module follows Intellia's 5-phase learner journey:

  Phase 1 — WONDER     → curiosity hook
  Phase 2 — STORY      → narrative-based concept introduction
  Phase 3 — SIMULATE   → sandbox-style interactive simulation
  Phase 4 — PLAY       → IntelliPlay™ gamified practice (100 questions)
  Phase 5 — REFLECT    → journal / LearnFlow AI prompt

2. PRODUCT VISION & GOALS

Vision

To make column addition and subtraction with 3-digit numbers intuitive, visual,
and memorable for 7–8 year old Singapore learners through animated column
algorithm simulations, place value scaffolding, regrouping (carrying/borrowing)
visualisations, and adaptive gamified challenge — all delivered in a consistent
Intellia experience.

Goals

Goal                         | Metric
-----------------------------|----------------------------------------------
Learning Completion          | ≥85% of students complete all 5 phases
Practice Engagement          | ≥90% attempt at least 10 practice questions
Score Achievement            | Average challenge score ≥75% first attempt
Session Duration             | Average engagement ≥18 minutes per session
Curriculum Alignment         | 100% aligned to Singapore MOE Primary 2
Phase Progression            | ≥80% reach Play phase in a single session
Regrouping Mastery           | ≥70% answer regrouping questions correctly

3. TARGET USERS

Primary: Grade 2 Students (Age 7–8)

  - Emerging readers; prefer visual scaffolding and animated feedback
  - Learning concrete-to-abstract (C → P → A): base-10 blocks → column
    layout → abstract number sentences
  - Short attention spans; need frequent micro-rewards and variety
  - Singapore context: familiar with local names, places, and school objects
  - Beginning to understand hundreds, tens, and ones place values

Secondary: Parents & Teachers

  - Assign as classwork or homework
  - Expect strict MOE Primary 2 curriculum alignment
  - Monitor via completion indicators and star ratings
  - May use the module on tablets in the classroom

Topic: Column Addition and Subtraction within 1000
Programme: Intellia SG Grade 2 Math

  - Targeting Mathematics Primary 2A / 2B (Casco Publications)
    → Chapter: Numbers to 1000
       • Hundreds, Tens, Ones (place value)
       • Counting and comparing 3-digit numbers
    → Chapter: Addition and Subtraction within 1000
       • Addition without regrouping (3-digit + 2/3-digit)
       • Addition with regrouping in the ones place
       • Addition with regrouping in the tens place
       • Addition with regrouping in ones and tens
       • Subtraction without regrouping
       • Subtraction with regrouping in the tens place
       • Subtraction with regrouping in the hundreds place
       • Subtraction with regrouping at two places
       • Word problems (1-step and 2-step)

  - My Pals Are Here! Math 2A / 2B (Marshall Cavendish)
    → Chapter 13: Addition and Subtraction within 1000
       • Column algorithm layout
       • Regrouping strategies
       • Let's Think Along / Let's Practise

  LO1: Understand place value — hundreds, tens, ones — in 3-digit numbers
  LO2: Add two 3-digit numbers using column method without regrouping
  LO3: Add with regrouping in the ones column (sum of ones ≥ 10)
  LO4: Add with regrouping in the tens column (sum of tens ≥ 10)
  LO5: Add with regrouping in both ones and tens columns
  LO6: Subtract using column method without regrouping
  LO7: Subtract with regrouping from the tens (borrow from tens)
  LO8: Subtract with regrouping from the hundreds (borrow from hundreds)
  LO9: Subtract with regrouping at two places
  LO10: Solve 1-step and 2-step word problems using column addition/subtraction

  Concrete   → Base-10 blocks (hundreds flats, tens rods, ones cubes) — simulated
  Pictorial  → Column layout diagram with H|T|O place-value columns
  Abstract   → Written algorithm with carried/borrowed digits

Number Ranges (phased difficulty):

  Phase A: Addition/Subtraction within 100 (2-digit warm-up)
  Phase B: Addition/Subtraction within 500 (3-digit, no regrouping)
  Phase C: Addition/Subtraction within 1000 (3-digit, with regrouping)

7. PHASE 3 — SIMULATION DESIGN (Detail)

7.1 Station A — Base-10 Block Builder (Concrete)

  Visual: Three columns (H, T, O) with draggable base-10 blocks
          Hundreds = flat squares (10×10 grids)
          Tens = rods (1×10 columns)
          Ones = unit cubes

  Interaction:
    - Child is given a 3-digit number, e.g. 256
    - Drag the correct count of hundreds flats, tens rods, and ones cubes
      into their respective columns
    - Blocks snap into place with a satisfying click animation
    - Correct count: column glows green; incorrect: gentle shake + retry

  Teaching: Builds place-value intuition before column algorithm

7.2 Station B — Column Addition with Regrouping (Pictorial)

  Visual: Two 3-digit numbers displayed in H|T|O column layout
          Interactive column cells (ones, tens, hundreds)

  Interaction:
    - Child taps the ones column to add ones digit by digit
    - If sum ≥ 10, a "Regroup" button glows — child must tap it
    - Animation: 10 ones cubes bundle into 1 ten rod and fly to tens column
    - "Carry digit" animates into the top of the tens column
    - Repeat for tens (if needed) and hundreds
    - Final answer verified when all columns filled

  Variants:
    - No regrouping (ones + ones < 10, tens + tens < 10)
    - Regrouping in ones only
    - Regrouping in tens only
    - Regrouping in both ones and tens

  5 problems per station; advance after 4/5 correct

7.3 Station C — Column Subtraction with Borrowing (Pictorial → Abstract)

  Visual: Two 3-digit numbers in H|T|O column layout (top minus bottom)

  Interaction:
    - Child taps the ones column; if top < bottom, a "Borrow" button glows
    - Animation: 1 ten rod breaks into 10 ones cubes and "fall" to ones column
    - Top ones digit updates (+10); tens digit decrements (−1)
    - Child enters the difference for each column using the number pad
    - Carries/borrows visualised with animated arrows and colour changes

  Variants:
    - No borrowing
    - Borrow from tens only
    - Borrow from hundreds only
    - Borrow at two places

  Teaching: The abstract "crossing out and writing" is physically felt first

8.5 MCQ Distractor Strategy (for all question types)

  Distractors are always within ±20 of correct answer (realistic errors):
    - Off-by-regrouping error: student forgot to carry/borrow
    - Column misalignment error: digit placed in wrong column
    - Sign error: addition instead of subtraction or vice versa
  All MCQs have exactly 4 options. Correct answer position randomised per session.

9. GAMIFICATION DESIGN

9.1 Reward System

  Stars (⭐): Earned per 10-question world set (1–3 stars based on score)
    3 stars: 9–10 correct  |  2 stars: 7–8  |  1 star: 5–6  |  0 stars: < 5

  XP Points:
    Correct first attempt  : 10 XP
    Correct second attempt : 7 XP
    Correct with hint      : 5 XP
    Streak Bonus           : +5 XP per correct answer when streak ≥ 5

  Streak 🔥: Fire counter for consecutive correct answers; resets on wrong answer

9.2 Badges (Unlockable)

  🏅 "Column Cadet"     — Complete Wonder + Story phases
  🥈 "Block Builder"    — Complete Simulate phase (all 3 stations)
  🥇 "Regroup Ranger"   — Score 80%+ on Play phase
  💎 "Perfect Column"   — Score 10/10 in any single world
  🔥 "Streak Blazer"    — Achieve a streak of 10+ consecutive correct answers
  🌟 "Column Champion"  — Complete all 5 phases (lesson complete)
  🧮 "Carry King"       — Answer 5 consecutive regrouping (addition) questions correctly
  📏 "Borrow Boss"      — Answer 5 consecutive regrouping (subtraction) questions correctly

9.3 Feedback Mechanics

  ✅ Correct:
     - Column cells highlight green one by one (animated cascade)
     - Bounce animation on the answer
     - Narration: "Brilliant! Your column method is perfect! 🎉"
       (celebration style: stability 0.12, similarity 0.45, style 0.75)

  ❌ Incorrect (first attempt):
     - Gentle red shake on the incorrect column
     - Narration: "Hmm, not quite! Let's check our columns again."
       (encouragement style: stability 0.16, similarity 0.50, style 0.65)
     - Hint 1 available: column diagram highlights the step where error occurred

  ❌ Incorrect (second attempt):
     - Hint 2: animated step-by-step column solve
     - Narration: "Let me show you — watch the ones column first!"
       (thinking style: stability 0.24, similarity 0.60, style 0.35)

  After 2 fails: Full animated explanation with narration, answer revealed
  No negative scoring — encouragement-first, always.

9.4 World Map (IntelliPlay™ Level Progression)

  World 1  — "Tens Town"        (Q1–10,   addition no regroup,        easy)
  World 2  — "Hundreds Hill"    (Q11–20,  addition no regroup,        medium)
  World 3  — "Carry Canyon"     (Q21–30,  addition regroup ones,      easy-med)
  World 4  — "Tens Tower"       (Q31–40,  addition regroup tens,      medium)
  World 5  — "Double Bridge"    (Q41–50,  addition regroup both,      hard)
  World 6  — "Subtract Valley"  (Q51–60,  subtraction no borrow,     easy)
  World 7  — "Borrow Bay"       (Q61–70,  subtraction borrow tens,   medium)
  World 8  — "Hundreds Harbor"  (Q71–80,  subtraction borrow hunds,  medium)
  World 9  — "Zero Zone"        (Q81–90,  subtraction borrow 2 place,hard)
  World 10 — "Number Palace"    (Q91–100, mixed addition+subtraction, hard)

  Each world unlocks only when ≥6/10 correct (1-star minimum)
  3 stars required for bonus "hidden challenge" in each world

9.5 Mascot (LearnFlow AI Companion)

  Character  : Friendly robot (matching Intellia branding — "LearnFlow")
  Mood states: idle | curious | happy | thinking | celebrating
  Appears in : Wonder hook, Story narration, Simulate guidance, Reflect phase
  Reacts to  : Correct answer, badge unlock, streak milestone, regrouping moment
  Unique      : Mascot holds a tiny "carry digit" flag during regrouping explanations

    ];
  }

11.5 Dynamic Fallback

  If any narration string is not found in audioMap.js (e.g. dynamically generated
  question text), the system falls back to the ElevenLabs /v1/text-to-speech API
  via the /api/elevenlabs proxy endpoint, using the per-style voice settings above.
  Fallback calls are rate-limited at 500ms between requests.

12. CONTENT REQUIREMENTS

12.1 Simulation Visuals

  Column H|T|O grid : SVG-rendered, colour-coded columns, animated borders
  Base-10 blocks    : Pixel-art style hundreds flats (green), tens rods (orange),
                      ones cubes (blue) — consistent with Intellia colour palette
  Carry indicator   : Animated superscript "1" that floats from ones to tens column
  Borrow indicator  : Animated "−1" on tens digit; "+10" on ones (borrowing shown)
  Number pad        : Circular, large (60px diameter), touch-friendly 0–9 grid

12.2 Question Bank Coverage

  All 10 question types × 10 questions = 100 unique questions
  Questions randomised per session (Fisher-Yates shuffle)
  No two sessions present the same question order
  MCQ distractors reflect realistic student errors (see §8.5)
  Column layout shown as visual aid for Q1–Q8; word problems use pictorial context

12.3 Word Problems — Singapore MOE Style

  Format: "[Character] had/has ___ [objects]. [Action involving ___].
            How many [objects] does [character] have [now/left/altogether]?"
  2-step word problems introduced in Hard difficulty worlds only
  Aligned to "Let's Think Along" style from Targeting Mathematics 2A/2B

12.4 Visual Difficulty Indicators

  Easy   : Green border on question card, 1 star label
  Medium : Yellow/amber border, 2 star label
  Hard   : Red/orange border, 3 star label
